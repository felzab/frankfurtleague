# Documentation standard

**Folder purpose:** the rules every document, comment, commit message and pull request body in this
repository is written to, and the two pages that make them copyable.

## Folder overview

| Read                                       | For                                                                                 |
| ------------------------------------------ | ----------------------------------------------------------------------------------- |
| [`standard.md`](standard.md)               | Writing or changing any documentation — every rule, one line each                   |
| [`shapes.md`](shapes.md)                   | Starting a spec sheet, an overview, a README or a module header — the shape to copy |
| [`worked-examples.md`](worked-examples.md) | Applying a rule — real passages from this repository, each shown before and after   |
