# Roadmap

**Verified against:** `cda2912d`, 2026-08-19\
**Folder purpose:** open items with their full analysis, the log of everything that has left, and the protocol they are all kept under.

## Folder overview

| Read                                   | For                                                                                                       |
| -------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| [`open-items.md`](open-items.md)       | What is open on the product, ranked — each entry with the analysis a decision needs                       |
| [`tooling-items.md`](tooling-items.md) | What is open on the toolchain and the documentation corpus, ranked the same way                           |
| [`closed-items.md`](closed-items.md)   | What happened to an item that is no longer listed, whichever page it left                                 |
| [`protocol.md`](protocol.md)           | Which of the two pages an entry belongs on, how it is ranked and closed, and when it belongs in a tracker |

## What belongs here

A **finding or an undecided question with real analysis behind it and no decision yet** — the
analysis is the deliverable, so the decision is taken with it in hand. Issue-shaped feature work is
parked here too, so it is ranked alongside everything else rather than left in the tracker.

Elsewhere: a decided thing is recorded where it will be read and argued in the commit that took it;
a defect under active remediation is a ledger row in `docs/audit/`; a contract the spec sheets track
stays there.
